# Support

Start with the [documentation index](docs/en/README.md). The Russian
translation is available at [docs/ru/README.md](docs/ru/README.md).

For a reproducible problem, open a GitHub issue using the bug-report template
and include:

- Symbraid version or commit, operating system, Python/Node version, and the
  selected client (CLI, VS Code, or Codex);
- the smallest safe reproduction and the exact command shape; and
- relevant logs with credentials, tokens, local paths, and personal data
  removed.

For a feature proposal, use the feature-request template. Questions and usage
discussions belong in the repository's public discussion channel when it is
enabled.

Do not put secrets in issues, pull requests, benchmark artifacts, or support
logs. For a suspected vulnerability, follow [SECURITY.md](SECURITY.md) and do
not disclose it publicly first.
