Дата ревью: 2026-09-03
Область: текущее рабочее дерево Symbraid
Reviewer: независимый агент, не участвовавший в написании проверяемых изменений
Вердикт: **ready**

## Контракт ревью

Замечания имеют severity P0 (критическая блокировка релиза), P1 (высокая
блокировка), P2 (исправить или обоснованно отклонить) и P3 (зарегистрированный
follow-up). Релиз нельзя принять при открытых P0/P1 или verdict `not ready`.

Проверялись Windows/Linux paths, независимость от хоста, watcher locking и
восстановление после прерывания, read-only контракт MCP, HTTP authentication и
изоляция проектов, сохранение sources, schema handling, redaction секретов,
паритет локалей и состав пакетов.

## Замечания и исправления

также удалены, поскольку проект новый и ещё не опубликован.

## Доказательства

- Python: 31 тест прошёл; один Linux-only тест path casing ожидаемо пропущен на
  Windows-хосте ревью.
- VS Code: прошли тесты контракта extension и Manage webview. Панель состояния
  читает `project.index_status`, логики индексации в extension нет.
- MCP: ровно три read-only инструмента; тесты покрывают loopback-only HTTP,
  bearer token, проверки Origin/Host и изоляцию bound project.
- Watcher: тесты покрывают duplicate lease, clean pre-stop и metadata при
  прерванном refresh.
- Storage: тесты требуют префикс `symbraid-` для новых Qdrant collections и
  активацию source только после успешной индексации.
- Документация: 17 пар English/Russian прошли tree parity, translation hash,
  root projection и link checks.
- Packaging: прошли сборка wheel/sdist и archive-secret scans; в wheel есть
  только entry points `symbraid` и `symbraid-mcp`.

## Цикл исправлений после ревью

Отдельный reviewer проверил исправления Windows status/search и Manage UI.
Первичный verdict содержал два замечания P2: ошибка верхнеуровневого запроса
настроек могла оставить webview без отображаемого состояния, а regression-
проверки не исполняли все ветки обработки ошибок. Загрузчик состояния UI вынесен
в чистый модуль, для всех исходов settings/status добавлены поведенческие тесты,
а core-тесты дополнены сценариями Windows path aliases, постоянной HTTP-ошибки,
исчерпания повторных попыток и скрытия секрета.

Тот же reviewer повторно проверил исправленный diff. Итоговый verdict — **ready**,
открытых P0, P1, P2 и P3 нет. Исправленный набор содержит 36 успешных Python-
тестов с одним platform-specific skip на Windows host, а также успешные проверки
VS Code, паритета/hash/links документации, версии и diff.

## Исправление вывода CLI и жизненного цикла watcher

Отдельный security-reviewer проверил границу сериализации CLI. Первый вариант
не скрывал некоторые формы Basic authorization и изменял допустимый текст
результатов поиска. Исправленная граница рекурсивно скрывает значения по
чувствительным ключам, применяет текстовую фильтрацию только к ошибкам и
используется обоими CLI entry points. Focused-тесты покрывают вложенные aliases,
credentials в URL, заголовки Basic и Bearer, представления mapping, неизменность
успешных результатов поиска, события watcher и ошибки MCP.

Отдельный reviewer watcher выполнил несколько повторных read-only проверок.
Были найдены и исправлены неограниченный буфер диагностики, устаревающее
состояние внешнего watcher, неверная классификация lock I/O, неполная
диагностика запуска, конкурентные запуски, поздний рестарт после dispose,
ошибки lock-файла после открытия и гонка между выполняющимся probe и явным
отключением auto-watch. Запуск теперь single-flight для каждого проекта,
диагностический хвост ограничен, внешние владельцы перепроверяются, а dispose
или явное отключение имеют приоритет над отложенной работой.

Те же reviewers повторно проверили исправленные границы. Локальный verdict —
**ready**, открытых P0, P1 и P2 нет. Доказательства: 45 успешных Python-тестов с
одним platform-specific skip на Windows, пять успешных тестов tooling,
успешные MCP handshake и read-only checks, тесты VS Code и webview, проверки
паритета/hash/links локалей, собранные wheel и sdist и пересобранный VSIX.
Hosted CodeQL и матрица CI Windows/Linux остаются обязательными release gates.
