# Интеграция VS Code

Расширение VS Code — тонкий клиент в пределах открытого workspace. Оно
запускает и останавливает watcher ядра и показывает статус, но не владеет
индексацией, embeddings, базами или миграциями.

## Граница workspace

Наблюдается только текущий workspace. Расширение не должно сканировать чужую
папку, смешивать проекты или изменять внешнюю коллекцию. Ядро остаётся
источником истины для одного managed source и impact plan миграции.

## Настройка

Установите artifact из `extensions/vscode-symbraid`. Параметр
`symbraid.executablePath` задавайте только если команда `symbraid` отсутствует
в `PATH`; пустое значение использует обычный launcher и совместимый fallback.
Не храните credentials в settings или workspace-файлах.

Команды manage и watcher показывают человекочитаемый статус. Для индексации,
смены backend и восстановления используйте [CLI](../cli.md) и [развёртывание
агентом](../operations/agent-deployment.md).
