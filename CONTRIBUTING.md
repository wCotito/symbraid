# Разработка

Основной язык документации и сообщений проекта — русский; идентификаторы и
форматы публичных API остаются английскими.

Перед изменениями ознакомьтесь с `AGENTS.md`. Изменения должны сохранять границу
между индексатором и read-only Codex plugin. Новая функциональность сопровождается
тестом и обновлением соответствующего документа в `docs/ru`.

Проверка выполняется командой:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\verify-windows.ps1
```

Не включайте в pull request локальные индексы, модели, API keys, `node_modules`,
VSIX или содержимое `%LOCALAPPDATA%\CodeIndex`.
